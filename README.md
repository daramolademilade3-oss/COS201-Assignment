## Description
This repository contains three foundational Java programs written for Week 3.
1. `SimpleCalculator.java` - A command-line calculator.
2. `AverageCalculator.java` - A program to find the average of N inputs.
3. `ItemCost.java` - A receipt calculator featuring subtotal and tax calculation.

## How to Compile and Run
Ensure you have the Java Development Kit (JDK) installed.

### Compile the files:
javac SimpleCalculator.java
javac AverageCalculator.java
javac ItemCost.java

### Run the files:
java SimpleCalculator
java AverageCalculator
java ItemCost
