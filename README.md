## Week 3: Variables, Data Types, Expressions and Input/Output

### Objectives
- Declare and initialize Java variables.
- Use appropriate primitive and reference data types.
- Perform arithmetic calculations.
- Read keyboard input using Scanner.
- Display formatted output.
- Compile, test and submit Java programs using GitHub.

### Programs Included
1. **`week03/SimpleCalculator.java`**
   - A command-line calculator taking two numbers to output sum, difference, product, and quotient.
2. **`week03/AverageCalculator.java`**
   - A program to find the total and average of N inputs.
3. **`week03/ItemCost.java`**
   - A receipt calculator featuring subtotal and tax calculations.

### How to Run
Open your terminal inside the `week03` directory and execute the following commands:

#### 1. Simple Calculator
```bash
javac SimpleCalculator.java
java SimpleCalculator
```

#### 2. Average Calculator
```bash
javac AverageCalculator.java
java AverageCalculator
```

#### 3. Item Cost Calculator
```bash
javac ItemCost.java
java ItemCost
```
